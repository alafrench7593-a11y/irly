# seo/

The state of IRLY's search work, kept in the repo so that each run starts from what the last one left.

| File | What it holds |
| --- | --- |
| `context.md` | What IRLY is and does, each fact with the file that proves it. The pages of the site say nothing that is not here. |
| `keyword-map.csv` | One row per search, the page that owns it, its status. No two pages own the same search. |
| `customer-journey.md` | How someone goes from « I know nobody here » to an account, and what they type at each step. |
| `ai-prompts.md` | The questions asked to AI assistants, and what each one answered on each dated check. |
| `backlog.md` | What to do next, ordered by expected effect for the effort. |
| `log.md` | One dated line per change shipped. |
| `dashboard.md` | The figures to follow each week and where to read them. |
| `directories.md` | Places where IRLY can be listed, with the text to paste. |
| `outreach/` | Drafts of messages to media and associations. Nothing here has been sent. |

Rules: no figure without its source and date; « not verified » rather than a guess; nothing is sent, submitted or bought from this folder without the owner.
